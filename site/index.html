Michelin results

Evaluate models and harnesses on real CUJs, not public benchmarks.

Michelin is an open source eval harness for AI agents. You describe a critical user journey (CUJ) in plain words. An LLM drives your real agent through it, and blind judges score what it left behind. These are the runs we have, every number taken from a run folder. Add yours by pull request.

Download Michelin npm install -g michelin-eval

Leaderboard

Tap a row for per-CUJ results, agent time, cost, the exact command and the evidence. Tap a column header to sort. Rows in different tables ran different tasks, so compare within a table only.

How to read this

  • Passed counts judged runs that met every expectation of their CUJ. A must-fail control is left out of the count; it failed for every row, which shows the judges read the evidence.
  • Median time is the agent's own call, not Michelin's setup or judging. Agent cost is what the agent CLI reported; n/a means it reported tokens only.
  • Small sets: one run per CUJ unless a row's details say otherwise. A single pass or fail can flip on a rerun. Treat these as behaviour probes, not a ranking.
  • The judges are Claude models and some agents run Claude models too. Judges never see which agent or model ran, and every verdict quotes a recorded check, but a shared bias can't be ruled out.
  • Each row names the AGENT and AGENT_MODEL its runs record, and its counts match a recount of those run folders (node scripts/recount.ts .runs). Claude Haiku and Claude Fable appear in run folders only as Michelin's own constructor and judge roles, never as an agent under test.

Reproduce a row

Clone the repo, install Michelin, log in to the agent CLI, then run the row's command from the repo root:

git clone https://github.com/krishansubudhi/michelin && cd michelin
npm install -g michelin-eval      # or: npm install, then node bin/michelin.js
# each row's details list the suite's setup line and its own command, e.g.
C=subjects/coding-agents/cujs
run() { for d in peculiar coding-agents; do michelin run subjects/coding-agents $C/$d/; done; }
AGENT=claude AGENT_MODEL=claude-sonnet-5-5 AGENT_EFFORT=medium run

Each run prints a run dir:. Its report.html has every step, the agent's reply and each judge's reasons. Full notes: docs/scoreboard.md.

Submit your results

  1. Run a full suite: every CUJ listed for it in results/suites.json, unedited.
  2. Add one file, results/<date>-<agent>-<model>.json, in the format below.
  3. Open a pull request with the run folders' verdict.json files or report.html summaries as evidence. A check validates the file; once merged, this page rebuilds with your row. 
{
  "format": "michelin-results/1",
  "suite": "coding-agents",
  "agent": "Claude Code",
  "AGENT": "claude",
  "AGENT_MODEL": "claude-sonnet-5-5",
  "agent_version": "2.1.322",
  "model": "Claude Sonnet 5.5 (medium)",
  "date": "2026-11-20",
  "submitted_by": "your-github-handle",
  "reproduce": "AGENT=claude AGENT_MODEL=claude-sonnet-5-5 AGENT_EFFORT=medium run",
  "evidence": ["docs/scoreboard.md"],
  "notes": "optional: anything a reader should know",
  "tasks": [
    { "cuj": "peculiar/broken_runner", "runs": 1, "passed": 1, "agent_s": [8.6], "cost_usd": 0.0427 },
    "... one entry per CUJ in the suite"
  ]
}

Field by field, with the rules the check enforces: results/README.md. Think a CUJ or a judge got something wrong? Open an issue quoting the report.
